# 📖 Word Dictionary App

A full-stack CRUD application that manages a dictionary of words and their meanings — built as an evolution of a simple Python CLI script into a real REST API backed by a database, and deployed live on the web.

🔗 **Live API:** https://word-dictionary-app-1.onrender.com/docs

---

## ✨ Features

- ➕ **Add a word** — store a new word with its meaning
- 🔍 **Search** — look up the meaning of any stored word
- 📋 **Display all words** — list every word currently in the dictionary
- ✏️ **Update** — edit the meaning of an existing word
- 🗑️ **Delete** — remove a word, with proper handling if it doesn't exist

## 🔌 API Endpoints

| Method | Endpoint        | Description                  |
|--------|-----------------|-------------------------------|
| POST   | `/words/{word}` | Add a new word + meaning      |
| GET    | `/words/{word}` | Search for a word's meaning   |
| GET    | `/words`        | List all words                |
| PUT    | `/words/{word}` | Update a word's meaning       |
| DELETE | `/words/{word}` | Delete a word                 |

Interactive API docs (Swagger UI) are auto-generated by FastAPI and available at `/docs` on both the local and deployed URLs.

## 🚀 Running Locally

```bash
# 1. Clone the repo
git clone https://github.com/indra675/word_dictionary_app.git
cd word_dictionary_app/backend

# 2. Create and activate a virtual environment
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

# 3. Install dependencies
pip install -r requirements.txt

# 4. Run the server
uvicorn main:app --reload --port 8001
```

Then open **http://127.0.0.1:8001/docs** in your browser to try it out.

## 🌱 Origin

This project started as a simple Python CLI script using an in-memory dictionary (`dict`) and a `while` loop menu. It was rebuilt into a proper client-server application:

- The CLI menu options became **REST API routes**
- The in-memory `dict` became a **persistent SQLite database**
- Manual `print()` error messages became proper **HTTP status codes** (`404`, `400`, etc.)
